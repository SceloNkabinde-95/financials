# Financials

A proposed secure, browser-based financial-statement preparation platform for South African accounting practices.

> **Current status:** early research and synthetic-data prototypes only. Not IFRS-compliant, not licensed for statutory financial-statement generation, and not approved for real client information.

Development takes place on feature branches and enters `main` through reviewed pull requests. See the open initial-build pull request for the first runnable prototype.

## Product direction

- Reusable, deterministic trial-balance-to-draft reporting engine
- Versioned, independently verified accounting-framework packs
- CSV/Excel/PDF import adapters, with optional opt-in premium OCR/AI interpretation
- Guided disclosures, traceable figures, review workflow, and eventual PDF/Word/Excel exports
- AWS-hosted multi-tenant SaaS **after** tenant-isolation, security, billing and compliance checks are complete

No production infrastructure or real-client data is authorised for this prototype.
